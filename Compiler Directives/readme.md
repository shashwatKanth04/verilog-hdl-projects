# Compiler Directives

Verilog designs demonstrating compiler directives such as `` `define `` and 
`` `include ``, using separate header files for macro definitions.

| File | Description |
|---|---|
| arithmetic_defines.vh | Macro definitions for arithmetic module |
| arithmetic_tb.v | Testbench for bit_arithmetic |
| bit_arithmetic.v | Arithmetic operations using `define macros |
| comp.v | Comparator using compiler directives |
| mux.v | Multiplexer using compiler directives |
| mux_defines.vh | Macro definitions for MUX module |
| mux_tb.v | Testbench for mux |
| priority.v | Priority logic using compiler directives |
| selectable_logic.v | Selectable logic using `define macros |

**Concept covered:** Compiler directives (`` `define ``, `` `include ``), header files
**Status:** Includes 2 testbenches (arithmetic_tb.v, mux_tb.v).
