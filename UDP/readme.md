# User-Defined Primitives (UDP)

Verilog designs implemented using User-Defined Primitives, covering both 
combinational and sequential UDP-based circuits.

| File | Description |
|---|---|
| add_sub_2b.v | 2-bit Adder/Subtractor |
| binary4_gray4.v | 4-bit Binary to Gray Code Converter |
| down_counter_3b.v | 3-bit Down Counter |
| even_parity_gen.v | Even Parity Generator |
| full_subtractor.v | Full Subtractor |
| johnson_counter.v | Johnson (Twisted-Ring) Counter |
| ring_counter.v | Ring Counter |

**Modeling style:** User-Defined Primitives (UDP)
**Status:** Testbenches to be added.
