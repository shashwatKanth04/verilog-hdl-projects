# Testbenches

Verilog testbenches and design files for verifying combinational and 
sequential circuit designs.

| File | Description |
|---|---|
| AddSub_4bit | 4-bit Adder/Subtractor |
| addsub4bit | 4-bit Adder/Subtractor (variant) |
| and_g | AND gate |
| bar_shift_tb | Testbench for Barrel Shifter |
| BCD | BCD Converter |
| bit4mul | 4-bit Multiplier |
| BtoGC_4bit | 4-bit Binary to Gray Code Converter |
| comp_8bit | 8-bit Comparator |
| decoder38 | 3:8 Decoder |
| demux14 | 1:4 Demultiplexer |
| FA | Full Adder |
| HA | Half Adder |
| Mul_8bit | 8-bit Multiplier |
| mux41 | 4:1 Multiplexer |
| PrioEnc_8to3 | 8:3 Priority Encoder |
| xor4_bit_comp | 4-bit XOR-based Comparator |

**Status:** Design and verification files for combinational logic modules.
