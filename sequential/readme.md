# Sequential Circuits

| File | Description |
|---|---|
| gray_counter.v | Gray Code Counter |
| johnson_counter.v | Johnson (Twisted-Ring) Counter |
| mod_10_count.v | Mod-10 (Decade) Counter |
| ring_counter.v | Ring Counter |
| up_down_count.v | Up/Down Counter |

**Design type:** Sequential (clocked) circuits
**Status:** Testbenches to be added.
