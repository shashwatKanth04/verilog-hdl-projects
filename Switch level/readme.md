# Switch-Level Modeling

Verilog designs implemented using switch-level primitives (MOS transistor-level 
modeling), representing logic gates at the transistor switch level.

| File | Description |
|---|---|
| compoundgate.v | Compound Gate (switch-level) |
| fulladder.v | Full Adder (switch-level) |
| nand.v | NAND Gate (switch-level) |
| nor.v | NOR Gate (switch-level) |
| xnor_g.v | XNOR Gate (switch-level) |
| xor.v | XOR Gate (switch-level) |

**Modeling style:** Switch-level (transistor-level primitives)
**Status:** Testbenches to be added.
