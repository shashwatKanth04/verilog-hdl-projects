# Delay & Timing

Verilog designs demonstrating delay modeling techniques — lumped delay, 
distributed delay, and pin-to-pin delay — used in gate and module timing.

| File | Description |
|---|---|
| distri1.v – distri3.v | Distributed delay modeling examples |
| lump6.v, lumped1.v – lumped5.v, lumped7.v | Lumped delay modeling examples |
| pin2pin_1.v | Pin-to-pin delay modeling |
| pp_2.v – pp_5.v | Additional pin-to-pin delay examples |

**Concept covered:** Delay modeling (lumped, distributed, pin-to-pin) using specify blocks and timing constructs
**Status:** Testbenches to be added.
