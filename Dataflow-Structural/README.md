# Dataflow & Structural Modeling

Verilog RTL designs implemented using dataflow (continuous assignment) and 
structural (module instantiation) modeling styles.

| Design | File | Description |
|---|---|---|
| BCD Converter | BCD.v | Binary to BCD conversion |
| 4-bit Multiplier | bit4mul.v | 4-bit multiplication |
| 4-bit Comparator | Comp_4bit.v | 4-bit magnitude comparator |
| Full Adder (Structural) | FAstruct.v | Full adder built from gate instantiations |
| CSA Multiplier | mult_csa.v | Multiplier using Carry-Save Adder architecture |
| 5:1 MUX | MUX_5to1.v | 5-to-1 Multiplexer |
| 4:1 MUX (Structural) | mux41_struct.v | 4-to-1 MUX using structural modeling |

**Modeling style:** Dataflow & Structural
**Status:** Testbenches to be added.
