# Procedural Assignments

Verilog designs using procedural blocks (always/initial), covering combinational 
and control logic implemented procedurally.

| File | Description |
|---|---|
| alu.v | Arithmetic Logic Unit |
| btogray.v | Binary to Gray Code Converter |
| comp8b.v | 8-bit Comparator |
| majority.v | Majority Function Circuit |
| mux21.v | 2:1 Multiplexer |
| mux41.v | 4:1 Multiplexer |
| parity8b.v | 8-bit Parity Generator/Checker |
| priority_enc.v | Priority Encoder |
| prioritvenc83.v | 8:3 Priority Encoder |
| segment7display.v | 7-Segment Display Decoder |
| updown4.v | 4-bit Up/Down Counter |

**Modeling style:** Procedural (always/initial blocks)
**Status:** Testbenches to be added.
