# Generate & Block Statements

Verilog designs using generate constructs and conditional (if/case) block 
statements for parameterized and scalable circuit design.

| File | Description |
|---|---|
| bit8_RCA.v | 8-bit Ripple Carry Adder (generate-based) |
| casearithmetic.v | Arithmetic operations using case statement |
| casegates.v | Logic gates modeled using case statement |
| evenparityxor.v | Even Parity Generator using XOR (generate-based) |
| inverter.v | Parameterized Inverter |
| mode.v | Mode-based control logic |
| Nbit_xor.v | N-bit XOR (generate-based, parameterized) |
| rcacla.v | Ripple Carry / Carry Look-Ahead Adder |
| widthadder.v | Parameterized width adder |

**Modeling style:** Generate blocks, if/case conditional statements
**Status:** Testbenches to be added.
